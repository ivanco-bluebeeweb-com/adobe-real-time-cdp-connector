# Adobe Real-Time CDP Connector — Preparation

**Category:** C36. Customer Data Platform (CDP)  
**Vendor URL:** https://business.adobe.com/products/experience-platform/real-time-customer-data-platform.html  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Adobe Real-Time CDP** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C36. Customer Data Platform (CDP)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **Enterprise CDP-архитектор** сталкивается с задачей: **управление единым профилем клиента в масштабах предприятия на базе стандартизированных схем XDM и сегментация в реальном времени**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Adobe Real-Time CDP переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **Enterprise CDP-архитектор, директор по цифровому маркетингу**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `проверка валидности схемы данных XDM -> получение профиля по идентификатору identity -> экспорт сегментов`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Adobe Real-Time CDP.
